Version 1.0 - Juillet 2025

1. Contexte Simplifié

Problème Central :

Gérer efficacement 3 flux critiques :
- 🚜 Machines (localisation, disponibilité, maintenance)
- 📑 Contrats (devis → signature → facturation)
- 👷 Personnel (compétences, affectations, documents)

Solution Proposée :
Une plateforme unique intégrant :
- Application Web (pour superviseurs/bureaux)
- Application Mobile (pour opérateurs terrain)
- Synchronisation temps réel entre tous les acteurs

2. Architecture en Image

[Odoo/Docuware] ← API → [Backend Rust] ←→ [PostgreSQL]  
                      ↑              ↓  
            [Web Next.js]     [Mobile React Native]

Analogie pour le profane :
- PostgreSQL = Grand classeur numérique organisé
- Rust = Moteur ultra-rapide et fiable
- Next.js = Interface bureau intuitive (comme un tableau de bord avion)
- Mobile App = Assistant terrain intelligent

3. Fonctionnalités Clés par Module

🔧 Suivi des Machines

  • Carte Temps Réel :
    • Machines en 🔴/🟢 selon disponibilité
    • Cliquer pour voir : client, contrat, chauffeur
  • Alertes Automatiques :
    • 📅 Assurance → Notification 30j avant expiration
    • ⚠️ Contrôle technique → Alerte directe au responsable

📝 Gestion des Contrats

  • Workflow 100% Digital :
graph LR
  A[Devis Odoo] -->|Auto| B[Signature Docuware]
  B --> C[Contrat Actif]
  C -->|Fin de mois| D[Facture Auto]
  • Avantage Métier : Réduction du temps de traitement de 5j → 1h

👥 Gestion du Personnel

  • Fiche Opérateur Intelligente :
    • Permis/Visites médicales : alertes avant expiration
    • Compétences : matching automatique avec machines
  • Planning Dynamique : Affectation en 1 clic

4. Application Mobile : Rôle & Suggestions d’Amélioration

Rôle Actuel dans le Cahier des Charges

  • ✅ Checklists Quotidiens
    • Contrôle technique basique
    • Signature numérique

Suggestions pour Maximiser l’Utilité

Fonctionnalité Impact Métier Coût Estimé
1. Scan QR Machine Élimine les erreurs de saisie +0 jour
2. Suivi Carburant Réduction coûts + détection anomalies +3 jours
3. Chat Intégré Communication directe chauffeur←→superviseur +5 jours
4. Mode Hors-Ligne Avancé Travail en zones isolées (chantiers) +10 jours
5. Rapport Photo Automatique Preuves pour assurances/clients +7 jours

Priorisation Recommandée :
1. Scan QR → Gain immédiat en fiabilité
2. Suivi Carburant → ROI rapide (économie 10-15% carburant)
3. Rapport Photo → Réduction litiges clients

Mode Hors-Ligne Fonctionnement 48h sans internet
Synchronisation différée		 Disponibilité en zones isolées

2. 💾 Backend Rust Minimaliste (20% du budget)

  • Synchronisation mobile : Transfert crypté AES-256 des checklists
  • Alertes automatiques :
// Vérification quotidienne à 6h
async fn check_alerts() {
    for machine in &machines {
        if machine.insurance_expiry - now() < 30.days() {
            send_alert(supervisor, machine);
        }
    }
}
  • Gestion contrats basique : Stockage PDF + rappels échéances

3. 📊 Tableau de Bord Web Essentiel (10% du budget)

Écran Contenu
Supervision Flotte - Taux complétion checklists
- Statut machines (🟢/🔴)
Alertes Centralisées - Documents expirés
- Anomalies terrain
Gestion Contrats Liste PDF + dates clés

Exclusions Stratégiques (Réduction des coûts)

  • 🚫 Carte temps réel → Remplacé par liste géotaggée
  • 🚫 Intégration Odoo/Docuware → Import/export CSV manuel
  • 🚫 Workflow signature électronique → Email avec PDF joint
  • 🚫 Reporting avancé → Export Excel brut
